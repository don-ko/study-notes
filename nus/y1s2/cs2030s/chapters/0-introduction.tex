\paragraph{Type Conversions}
Suppose $\verb|S|<:\verb|T|$.
Then implicit type conversion from \verb|S| to \verb|T| (narrowing) is allowed.
Type conversion from \verb|T| to \verb|S| (widening) requires type casting.
